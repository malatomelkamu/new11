Neural Architecture & Pipeline Blueprint

An overview of the underlying computational graphs driving our 4 diagnostic models.

1D-CNN Pipeline

  • • Input shape: (200, 1) heartbeat window
  • • Conv1D filters: 32 → 64 → 128
  • • Batch Normalization & Max Pooling
  • • Global Average Pooling & Dropout (0.4)
Loss: Binary Crossentropy

HistGradientBoosting

  • • Feature Engineering (Interactions & Ratios)
  • • Stratified 5-Fold Cross Validation
  • • Balanced class weight optimization
  • • Fast histogram-based binning splits
Metric: ROC-AUC / F1

Balanced Random Forest

  • • 15 Multidimensional Survey Features
  • • Automated threshold tuning (0.74 cutoff)
  • • Maximized sensitivity for high-risk flags
  • • Zero-leakage train/test partitioning

EfficientNetB0 + Grad-CAM

  • • ImageNet pre-trained backbone
  • • Two-phase warmup & fine-tuning
  • • On-the-fly tf.data augmentation
  • • Grad-CAM spatial heatmap explainability
